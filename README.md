# 🧠 Student Psychological Assessment Web Application (Ujian Psikologi Pelajar)

A modern, interactive, mobile-first web application designed for school and university students to take 8 standardized psychological and self-assessment tests.

---

## 📋 Standardized Psychological Tests Included

1. **DASS-21 (Depression, Anxiety & Stress Scale)**
   - 21-item psychometric scale measuring Depression, Anxiety, and Stress levels.
2. **Inventori Gaya Bercinta (IGB)**
   - 60-item inventory assessing Hendrick's 6 Love Styles (Eros, Ludus, Storge, Pragma, Mania, Agape).
3. **Inventori Pengurusan Masa Pelajar**
   - 9-item weekly time-tracking inventory evaluating study balance against 168 available hours/week.
4. **Beck Depression Inventory (BDI-Malay)**
   - 20-item symptom category assessment for physical, emotional, and cognitive depression levels.
5. **MBTI Personality Test (Myers-Briggs Type Indicator)**
   - 70 forced-choice paired items mapping to 16 personality types (e.g. INFJ, ENFP, INTJ, ESTP).
6. **Saringan Minda Sihat**
   - 18-item health screening combining Whooley (2 items), PHQ-9 (9 items), and GAD-7 (7 items) with automatic self-harm risk detection.
7. **Soal Selidik VARK (Gaya Pembelajaran)**
   - 7 scenario items determining Visual, Auditory, Read/Write, and Kinesthetic learning preferences.
8. **The Five Love Languages Test (Dr. Gary Chapman)**
   - 30 forced-choice pairs discovering primary and secondary love languages.

---

## ✨ Features

- **Mobile-First Responsive Design**: Optimized for smartphones, tablets, and desktop displays.
- **Glassmorphism UI System**: Sleek modern dark mode UI with interactive cards and animations.
- **Sticky Mobile Navigation Bar**: Touch-friendly 48px+ targets for easy single-thumb navigation.
- **Interactive Results Visualizer**: Dynamic subscale progress bars and visual indicator badges.
- **Print & Export Laporan**: One-click printable PDF summary reports.
- **LocalStorage Persistence**: Auto-saves completed test history.

## 🚀 Getting Started

Simply open `index.html` in any web browser, or run a local static server:

```bash
python -m http.server 8080
```
Then visit `http://localhost:8080` in your web browser.
